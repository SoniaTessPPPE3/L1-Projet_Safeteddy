Pendant toutes les séances, je me suis occupé de la partie alerte sonore du projet Safe Teddy.

Mon travail principal était de programmer le buzzer pour qu’il fasse un bip quand un enfant s’approche à moins de 50 cm de la zone interdite détectée par le capteur à ultrasons.

Au début, j’ai essayé de comprendre comment fonctionnait le buzzer et comment le brancher sur la carte électronique. Grâce à l’aide du professeur et à un schéma de branchement, nous avons réussi à savoir où placer les fils et comment connecter les composants correctement.

Ensuite, j’ai travaillé sur le code du buzzer. Pour nous aider, nous avons utilisé le GitHub de Monsieur Ferrero, où il y avait déjà des exemples de codes pour faire fonctionner un buzzer. Nous avons repris certaines parties du code et nous les avons ajoutées à notre propre programme pour que cela fonctionne avec notre projet.

J’ai fait plusieurs tests pour essayer de déclencher le son seulement quand une présence était détectée à moins de 50 cm.

Pendant les essais, nous avons eu plusieurs problèmes : parfois le buzzer sonnait en continu ou le code ne marchait plus correctement. J’ai donc aidé à chercher les erreurs dans le programme et à modifier le code pour améliorer le fonctionnement du système.

J’ai aussi participé aux branchements des différents composants pour vérifier que tout était bien connecté entre le capteur, le buzzer, la LED et la carte électronique.
